# uoregions

[![CI](https://github.com/draxinar/uoregions/actions/workflows/ci.yml/badge.svg)](https://github.com/draxinar/uoregions/actions/workflows/ci.yml)

Web-based editor for Ultima Online server `regions.txt` files. Scroll
and zoom the Britannia map, draw or resize region rectangles directly
on the canvas, edit their properties in the sidebar, and save back to
`regions.txt`.

Pure vanilla HTML/CSS/JS, no build step, no dependencies.

Live at <https://uoregions.serpent-isle.com/>.
